# Changelog

## 0.1.0

- First public release.
- Persistent companion agent with a hidden Session and a floating Web panel.
- Mood, energy, affection, real-time clock, and autonomous moments.
- Default personas: 大肥鱼, 小深, 夜灯; custom persona editor.
- Per-persona diary files with an index and a folder-opening action.
- New-chat action that keeps diaries, mood, energy, and affection.
- No local computer control: shell, local file tools, jobs, subagents, and
  workflow tools are denied for the companion.
- Default tool approval policy is `ask`.
