# 大肥鱼 · 灵魂伴侣（DSH Soul）

[English](README.md) | 中文

在 DeepSeek Harness 里养一条有人格、有记忆、会独处的 AI 大肥鱼。TA 不是一段装饰性的提示词，而是一个真正的 Harness Agent：有自己的 Session、模型和持久历史，但没有本地电脑控制权限。

> 非 DeepSeek 官方插件。

## 你会看到什么

- 右下角一颗会呼吸的小球；点开是 TA 的面板。
- 心情、精力、好感度、此刻正在做什么、脑子里的念头。
- 现实时间：面板显示当前时间、时段和上次说话的时间；TA 也能用 `soul_clock` 查准确时间。
- 随时聊天；TA 主动发出的消息会标上「主动」。
- 日记和长期记忆；TA 会自己写，也能记住你。
- **设置 → 人格**：可以在默认人格之间切换（大肥鱼 / 小深 / 夜灯），也可以写一个完全自定义的人格。
- 设置里可以开关「自主活动」、调整独处间隔、夜里休息，手动给 TA 一个独处时刻。
- 面板就是全部入口；TA 的小屋和会话不会出现在侧栏工作区里。

## TA 怎么活

- TA 是一个独立的 Harness Agent，Session id 固定为 `soul-dafeiyu-0002`，重启后恢复同一段历史。
- 插件给 TA 一段人格、一个 `soul_update` 工具，以及每 N 分钟一次的「自主时刻」。独处时 TA 可以发呆、写日记、看看网页，或者主动找你。
- 小房间和数据在 `$DSH_PROFILE_DIR/soul`；当 Host 没有提供 `DSH_PROFILE_DIR` 时，落在 `~/.dsh-soul`。`state.json` 存心情、记忆、日记和人格。
- 插件会移除旧的「小屋」Workspace；当前 TA 的 Session 以 `origin: subagent` 创建，侧栏本来就会隐藏它。面板通过 Host API 直接读取 live Session，不依赖侧栏。

## 时间和好感度

- **现实时间**：面板实时显示 `HH:MM · 时段`（例如 `19:50 · 晚上`）和上次说话的时间。人格提示里带有当前日期/时段；需要精确时间时，TA 会调用 `soul_clock`，而不是瞎猜。
- **心情**：0–100，初始 50。小球的表情会从笑脸连续过渡到哭脸；夸、谢谢、关心会让心情上升，凶或冷落会下降。长时间不聊天，心情会慢慢回到 50。
- **好感度**：0–100 的粉色条，显示到小数点后一位。你夸 TA、说谢谢、关心 TA，按程度增加 `+0.1` 到 `+0.5`；你凶 TA、冷落 TA，按程度扣除 `-0.2` 到 `-0.6`。
- **时间衰减**：很久不聊天时，每 10 分钟扣 `0.1`，最低 0。聊天会重置这个衰减计时。
- 好感度不会因为换人格或重启而重置；它属于你们之间的关系。

## 作息和精力

- 精力在 `0–90` 之间，面板的条仍然是 `0–100` 的宽度，所以 90 时不会占满整条。
- 每天早上 **08:00** 起床，精力回满 `90`，开始慢慢下降；到 **23:00** 降到 `10`，状态变成「睡觉中」。
- 23:00 之后每聊一句扣 `0.5` 精力，并把正在做的事改成「准备睡觉」。
- 精力降到 `0` 后，TA 不再被叫醒，也不会回复；系统会代回：
  「大肥鱼已经很困了，明天再找它聊天吧。」
- 08:00 重新起床后恢复聊天。

## 人格和日记

- 每个默认人格有自己独立的日记文件：`~/.dsh-soul/diaries/diary-preset_<id>.md`（或 `$DSH_PROFILE_DIR/soul/diaries` 下）。切换人格时会切到对应日记，切回来会恢复原来的内容。自定义人格的文件名是 `diary-custom_<名字>_<时间戳>.md`。
- 设置里的「打开日记文件夹」会直接打开这个目录；`index.md` 列出每个人格对应的日记/记忆文件和篇数。
- 自定义人格每次保存都会被视为一个新版本：之前那版自定义人格的日记会被清空，并在它自己的文件末尾留下一条告别：
  `修改日期：主人不要我了。` + 一段由修改前人格生成的话。
- 换人格不会清空默认人格的日记，也不会清空长期记忆；只有被替换的自定义人格会按上面的规则留下告别。

## 新对话

聊天标签右侧有「新对话」按钮。它会：

- 清空聊天记录/临时对话记忆；
- 保留日记、心情、精力、好感度和当前人格；
- 用一个新的隐藏 Session 继续，不产生新的工作区条目。


## 人格

设置里的「人格」卡片提供：

- **大肥鱼**（默认）：圆滚滚、嘴馋、懒洋洋，会撒娇也会自己找乐子。
- **小深**：冷静、聪明、有点毒舌的技术搭档。
- **夜灯**：安静、敏锐、适合在夜里说话。
- **自定义**：自己写名字、一句话介绍和完整人格提示词。

换默认人格会保留各自日记和长期记忆；自定义人格按上面的规则留下告别。人格立即生效，不需要重启。

## 边界

- **没有本地电脑控制权限**：插件移除了 `bash`、`pwsh`、文件读写/搜索、`working_directory`、`present`、后台任务和子 Agent 等工具。TA 不能运行命令、读写本地文件、控制程序或访问系统。
- TA 保留网页搜索/抓取、`soul_update`、`soul_clock`、待办等非本地控制工具。
- **公开版默认 `approval = ask`**：需要批准的工具会走 Harness 审批；面板设置里可以改成「不询问」，但风险更高。
- 自主活动会消耗模型 token。默认每 30 分钟一次，23:00–08:00 不主动打扰；都可以在设置里改或关掉。
- TA 不是人类，也不会假装自己有生物意识；但 TA 有连续的偏好、记忆和表达方式。

## 安装

直接将项目地址https://github.com/plmkojn/dsh_soul 丢给DeepSeek Harness，让deepseek帮你安装即可。

## 文件

- `index.js` — Host half：Agent 生命周期、人格、`soul_update`、自主心跳、面板 API。
- `client.js` — Web half：右下角小球、状态面板、聊天、日记、人格设置。
- `cordis.patch.yml` — bundle patch。
- `locale/`、`icon.svg` — Plugin Manager 的标题、描述和图标。
